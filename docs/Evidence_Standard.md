# Evidence Standard

## Naming convention

Use:

`<test-case-id>_<short-description>_<result>_<yyyymmdd>.<ext>`

Example: `TC-CART-001_add-product_pass_20261020.png`

## Evidence requirements

- Capture the relevant screen, not the entire desktop where possible.
- Keep the URL, visible error and key state readable.
- For a failure, include before/after evidence when state changes matter.
- Link the evidence filename from the Excel result or defect report.
- Review every file before sharing it.

## Privacy and storage

Store execution evidence in the ignored `evidence/` folder. Use synthetic accounts and values only. Never commit passwords, tokens, personal information or production data.
