## Mission

Explore the selected feature to discover failures that scripted cases may not cover, while protecting test data and the local environment.

## Heuristics

- Empty, maximum and unexpected input
- Refresh, back navigation and duplicate clicks
- Add/remove/re-add state transitions
- Session timeout or logout during a journey
- Narrow viewport and visible error recovery
